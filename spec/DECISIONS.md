# Decisions

This document holds the decisions that govern FuguSeed. A plan must not go
against a decision. To change a decision, propose the change and get human
approval first.

| ID   | Decision                                                                                                                                                                                                                                                               | Rationale                                                                                                                                                                                                                                                                                                                                 |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-01 | Two programs exist, with two trust levels. `fuguseed-words` must never read, print, or hold a seed word, and it can run on any computer. `fuguseed-qr` reads the 12 words, and it must run on an air-gapped computer only.                                             | A word sheet and a manual are public. The words are the whole secret. A program that sees them must be small enough to audit and must run where no network exists.                                                                                                                                                                        |
| D-02 | No program generates a seed word. The dice give the entropy, the paper holds the words, and a device that accepts BIP39 words finds the check word. The programs print the address space, check the print, and encode the result.                                      | A tool that contributes no entropy needs no random source and no audit of one. A person can prove each word against the print with the dice alone.                                                                                                                                                                                        |
| D-03 | The artifacts name the standards, for example BIP39 and SeedQR, and never one application of them. No file that the repository owns holds the word `bitcoin`, `crypto`, `cryptocurrency`, or `money`. A test enforces the rule.                                        | The standards serve more than one use, and password management is one of them. A name of one application narrows the reader and dates the artifact.                                                                                                                                                                                       |
| D-04 | The word count is 12, and the SeedQR is a Standard SeedQR of 25 x 25 modules. No program accepts 24 words, and no program emits a Compact SeedQR.                                                                                                                      | With 12 words, the check word is one of 16 candidates that a person can try on a device. With 24 words, it is one of 256. A Standard SeedQR decodes to a digit string that a person can map back to words. A Compact SeedQR does not.                                                                                                     |
| D-05 | The dice are a d8 and two d16, with faces 1 to 8 and 1 to 16. YELLOW d8 selects the block, BLUE d16 the row, and RED d16 the column. The word index is `(Y-1)*256 + (B-1)*16 + (R-1)`.                                                                                 | 8 x 16 x 16 is 2048, so one throw selects one word with no re-roll, no rejection, and no bias. The printed sheet is the address space, so the person does no arithmetic. The d8 has the fewest faces, so it is the coarsest selector.                                                                                                     |
| D-06 | `fuguseed-words` builds on the Fugu library: `Fugu::CLI` for the verbs, `Fugu::File` for the share files. It installs as part of the `App-FuguSeed` distribution.                                                                                                      | One toolchain serves the organization. The program sees no secret, so an installed library costs nothing in trust.                                                                                                                                                                                                                        |
| D-07 | `fuguseed-qr` runs on core Perl v5.34 with no dependency outside the Perl base. `Digest::SHA` is the one core module that it loads. The release ships it as one packed file that `scripts/pack` builds from the modules of this repository, with no Fugu module in it. | One file crosses to an air-gapped computer with one digest and no install step. A person can read the whole file. `Digest::SHA` ships with every Perl since 5.10, and the BIP39 check word needs SHA-256.                                                                                                                                 |
| D-08 | The mask pattern of the SeedQR is pattern 0, always. `fuguseed-qr` evaluates no penalty score.                                                                                                                                                                         | Every mask pattern gives a code that any reader decodes, because the format bits name the pattern. The penalty rules of the QR standard are ambiguous on one count, and two libraries select two masks for one input. The reference image of test vector 4 of the SeedQR specification is mask 0, so one image proves the whole pipeline. |
| D-09 | The word sheet is class-less HTML5 in one file. The build inlines the shipped style sheet, and the check compares the inlined style sheet with the shipped one byte for byte. The check parses the sheet as one strict grammar from the first byte to the last.        | A style rule can reverse or hide a row on paper while the text order stays correct. A grammar that rejects every unknown byte leaves no place for a decoy cell, a comment, or a script.                                                                                                                                                   |
| D-10 | The English list is the one word list. It ships as a share file for `fuguseed-words`, and as an embedded copy in the list module for `fuguseed-qr`. One test holds both copies to one pinned SHA-256.                                                                  | BIP39 discourages every other list. The packed program must carry the list, because an air-gapped computer has no second file. The share file is the input that a person can inspect and replace.                                                                                                                                         |
| D-11 | The 12 words enter `fuguseed-qr` on standard input only. No argument, no file name, and no environment variable carries a word.                                                                                                                                        | An argument is visible in the process list and in the shell history. A file is a copy on disk.                                                                                                                                                                                                                                            |
| D-12 | `fuguseed-qr` has no option and no verb. Simplicity and auditability beat ergonomics in every choice about it.                                                                                                                                                         | Every option is a code path that an auditor must read. The program runs a few times in the life of one seed.                                                                                                                                                                                                                              |
| D-13 | The manuals are hand-written mdoc pages. The offline procedure is one page, `fuguseed(7)`, in ASD-STE100 Simplified Technical English. It names the dice by color and the device by the word "device".                                                                 | A man page prints with `man -t`, and it holds no color. The color names of the dice are words on the sheet, so they survive a black print. The procedure must work with any device that accepts 12 BIP39 words.                                                                                                                           |
| D-14 | The procedure writes the loss of the seed words as a WARNING, not as a CAUTION.                                                                                                                                                                                        | ASD-STE100 reserves WARNING for an injury and CAUTION for damage. The only harm in this procedure is an irreversible loss, and a reader acts on the stronger form. This is a deliberate deviation.                                                                                                                                        |
| D-15 | FuguSeed must not require a change to Fugu, FuguPass, or FuguOracle. The FuguPass specification is the reference consumer of the SeedQR, not a requirement.                                                                                                            | The sheets and the SeedQR follow public standards, so any device and any consumer can use them. A dependency on a sibling change blocks a release.                                                                                                                                                                                        |
